# 講義指標清單與資料來源對照

> 整理日期：2026-10-18｜來源：郭維裕《Fantastic Economic Indicators》講義（`Docs/Ref/`，頁碼 `[K n]` 為整份 193 頁的頁碼；1-2 檔第 n 頁 = K 128+n）。
> 「FRED」欄的序列於 2026-10-18 用 `https://fred.stlouisfed.org/graph/fredgraph.csv?id=<ID>` 實測可抓（不需 API key）。
> 時序屬性：領先 L／同時 C／落後 G（照講義標題）。內容為摘要，非逐字抄錄。

## 講義總則

- 三類指標：領先（經濟往哪走）、同時（現在狀態）、落後（經濟去過哪）[K 3]。
- 指標常是估計值，會修正；多數須季節調整。**越多指標指向同方向，越可能是真的經濟現象** [K 4]。
- 選指標四準則：即時性、準確性、少人用（exotic）、與實體經濟／投資的連結 [K 5]。
- 分類骨架 GDP = C + I + G + NX，另加 MC、IFU；本講義聚焦 30+ 個領先／同時指標 [K 6]。

## 講義圖表頁補充（SU-03，詳見 [郭維裕講義-圖表頁摘要.md](郭維裕講義-圖表頁摘要.md)）

- **全部是美國資料**（加少數全球商品：銅、LME 鋁／鎳、BDI、黃金），**沒有台灣指標**。
- **固定圖表格式**：原值＋3 個月移動平均（QMA）＋12 個月移動平均（YMA）＋NBER 衰退陰影，下一頁配 YoY 圖。Dashboard 詳細圖照此格式（UI-02）。
- **門檻線**：PMI 50、Sahm Rule 0.5、債務 YoY 3%、期限利差 0、損益兩平通膨 2%、VIX 12／20（手繪 30／40）、費城聯準會 0、消費者信心與非農 YoY 的 0 線。
- **雙軸對照**：U6 vs 因經濟因素兼職（`LNS12032194`）、初領 vs 續領、`DGORDER` vs `ACDGNO`、總房貸 vs 商業房貸、費城聯準會當前 vs 未來。
- **G 區 [K 69–91] 其實是「美國債務與槓桿」**：每種債務做「水準／YoY／占 GDP／占 GDP 的 YoY」四張一組。序列：聯邦總債務 `GFDEBTN`、債務/GDP `GFDEGDQ188S`、住宅房貸 `HMLBSHNO`、總房貸 `MABSHNO`、商業房貸 `CMLBSHNO`、學貸 `SLOASM`、循環信用 `REVOLSL`、車貸 `MVLOASM`；分母 `GDP`。P69「SLOP」= slope，指每次衰退後債務斜率變陡。
- **IFU 圖片區 [K 136–156、159–177]**：2022/5–2024/2 CPI、PPI 歷次公布案例（BLS 截圖，標 MoM／YoY），以及總指數 vs 核心、食品／能源／服務分項。
- **講義圖上用的 FRED 序列（與上表不同或補充）**：`ALTSALES`（輕型車銷售）、`SAHMCURRENT`、`PCEDG`（PCE 耐久財）、`DGS10`、`M2NS`、`T10Y2YM`、`CPIAUCNS`、`PPIACO`、`BAA10YM`、`T10YIEM`。
- **非 FRED 來源（講義用 Bloomberg／Yahoo）**：CCI `CONCCONF`、ISM `NAPMPMI`／`NAPMNMI`、LME 鋁／鎳庫存 `LSAH`／`LSNI`、BDI `BDIY`、原油庫存 `DOESCRUD`、黃金 `XAUUSD`、美元指數 DXY（Yahoo）。這些都需要 DA-04 決定替代方案。
